# Root Books Tabs (retired)

> [!IMPORTANT]
> Root Books Tabs is retired and will not receive further updates. Use
> [Root Books Workspace](https://github.com/VingGit/obsidian-root-books-workspace) for
> the maintained replacement.

Root Books Workspace keeps the portable book metadata, note workflow,
companion-plugin auditing, selective sorting refreshes, and passive book
appearance needed by the current Root Books ecosystem. It intentionally leaves
the old managed-tab, pop-out, grid, pseudo-tab, and Explorer replacement system
out of its initial release.

The final legacy Root Books Tabs release is `0.1.8`. Its Obsidian plugin ID is
`scope-tabs`. The source and release remain available for historical reference,
but the plugin is unsupported and should not be used for new vaults.

The retired implementation and its later experimental work remain preserved in
this repository's Git history and archive branches.
